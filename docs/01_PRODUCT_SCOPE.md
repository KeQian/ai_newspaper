# P0 产品范围基线

> 状态：已冻结，可进入实现
> 时区：Asia/Shanghai
> 详细页面说明见 `AI_NEWS_PRODUCT_SPEC.md`

## 1. 产品目标

为中文 AI 从业者提供可验证、低噪声、可持续更新的热点动态聚合站。P0 的核心闭环是：

1. 自动发现候选动态；
2. 编辑审核并发布结构化内容；
3. 用户浏览、检索、筛选和订阅邮件；
4. 运营人员追踪来源、任务、内容质量与异常。

## 2. P0 用户与任务

### 2.1 读者

- 快速了解今天值得关注的 AI 动态；
- 判断事件的重要性、证据与影响；
- 按主题、实体和时间检索历史信息；
- 订阅日报或周报。

### 2.2 编辑与管理员

- 处理系统生成的候选事件；
- 校验来源、合并重复事件、修订摘要；
- 发布、下线与更正内容；
- 管理来源和查看采集任务运行情况；
- 编辑并发送 Newsletter。

## 3. P0 包含范围

### 3.1 公开站点

| 能力 | 路由 | P0 验收结果 |
|---|---|---|
| 首页 | `/` | 展示置顶、最新、热门主题与 Newsletter 入口 |
| 最新动态 | `/latest` | 支持分页、时间、主题、类型与来源筛选 |
| 日报 | `/briefing/[date]` | 展示指定北京时间日期的编辑简报 |
| 内容详情 | `/news/[slug]` | 展示摘要、影响、时间线、实体和至少一个原始来源 |
| 深度分析 | `/analysis/[slug]` | 展示长文、目录、引用和相关阅读 |
| 主题页 | `/topics/[slug]` | 展示主题说明、趋势与相关内容 |
| 搜索 | `/search` | 支持关键词、分页、筛选、空状态和错误状态 |
| Newsletter | `/newsletter` | 支持订阅、双重确认、退订和隐私说明 |
| 静态页 | `/about` `/methodology` `/privacy` `/terms` `/corrections` `/ai-disclosure` | 可访问、可索引、内容完整 |

| 能力 | 路由 | P0 验收结果 |

| 审计日志 | `/admin/audit` | 查询关键管理操作 |

## 4. 明确不在 P0

- 公开用户注册、登录与个人账户；
- 收藏、关注、个性化推荐与通知中心；
- 会员、支付、广告自助投放；
- 用户评论、投稿与社区；
- 原生 App、多语言和多租户；
- AI 自动发布、AI 自动发送 Newsletter；
- 抓取受限正文或绕过 robots.txt、登录墙、付费墙和反爬机制。

## 5. 关键业务规则

1. 所有公开内容必须有 `published_at`、`primary_source_url`、`source_count` 和编辑审核记录。
2. 高影响事件发布前至少两条独立来源；仅有官方一手来源时允许单来源，但必须标记为官方发布。
3. AI 只能生成候选、标签和摘要草稿；发布、下线、更正和邮件发送必须由管理员触发。
4. 来源失败不得阻塞其他来源；失败进入重试与人工处置队列。
5. 原文只存必要元数据和短摘录；不镜像完整受版权保护正文。
6. 删除来源不级联删除已发布内容；内容保留来源快照用于审计。
7. 所有展示时间按 Asia/Shanghai 输出，数据库存 UTC。

## 6. 非功能基线

- 可用性：月度 99.9%，计划维护除外；
- 性能：首页与列表页缓存命中时 P95 服务端响应小于 500ms；公开 API P95 小于 800ms；
- 无障碍：核心流程达到 WCAG 2.2 AA；
- 安全：管理后台强认证、RBAC、CSRF 防护、审计日志、输入校验与速率限制；
- SEO：服务端渲染、canonical、结构化数据、站点地图和正确的 HTTP 状态码；
- 数据时效：核心官方来源目标 60 分钟内生成候选，一般来源 6 小时内；
- 可观测性：结构化日志、错误追踪、指标、任务批次与来源级告警。

## 7. 完成定义

P0 只有在以下条件全部满足时才算完成：

- `11_TEST_ACCEPTANCE.md` 中 P0 场景全部通过；
- OpenAPI 与实际接口一致，CI 中有契约校验；
- 数据库迁移可从空库执行，回滚方案经过验证；
- 采集任务连续 14 天达到时效与成功率目标；
- 备份恢复演练、故障降级和发布回滚通过；
- 隐私、条款、来源使用规则和 Newsletter 同意文案完成审核；
- 没有严重级别为 P0/P1 的安全缺陷和未处理的发布阻断项。
