# 编辑后台页面级需求

## 全局规则

- 后台路由统一 `/admin/*`，未认证跳转 `/admin/login` 并保留安全返回地址。
- 桌面优先，最低支持 1024px；768px 可审核，手机仅允许查看告警，不允许发布和批量操作。
- 左侧导航：概览、候选事件、内容、来源、任务、实体、Newsletter、审计。
- 顶部显示环境标识、数据延迟、任务告警和当前角色。
- 所有修改使用乐观锁；冲突时展示差异，不能覆盖他人修改。

## `/admin/login`

目标：安全进入后台。包含邮箱/身份提供方、二次验证、错误和冷却状态。不能透露未注册管理员；连续失败触发限流。验收：禁用账户、错误 MFA、过期返回地址、开放重定向均被安全处理。

## `/admin`

目标：10 秒内判断内容生产是否健康。

- 待审核候选、待发布稿件、失败来源、失败任务、Newsletter 状态。
- 最近 24 小时采集量、去重率、编辑接受率、核心来源延迟。
- 快捷入口只显示当前角色允许的操作。
- 无异常时明确显示“系统正常”，不能用空白代替。

## `/admin/candidates`

- 筛选：状态、时间、来源、主题、实体、风险、重要度。
- 列：事件时间、标题、主要来源、来源数、评分、风险、状态、负责人。
- 支持多选拒绝/分配；合并必须在详情页完成。
- URL 保存筛选、排序和游标；返回后恢复位置。
- 空状态区分“无新候选”和“筛选无结果”。

## `/admin/candidates/[id]`

三栏审核：左侧原始来源，中间候选事实与 AI 建议，右侧实体、评分、风险和操作。

操作：创建草稿、合并到事件、拆分来源、拒绝、延后、标记提示注入。创建草稿前必须至少保留一个一手/官方来源，或填写例外理由。所有操作写审计；来源页面在隔离预览中打开，不执行脚本。

## `/admin/content`

- 标签：草稿、审核中、已排程、已发布、已更新、已撤回。
- 列：标题、类型、状态、作者、更新时间、排程/发布时间、来源健康度。
- 支持分配编辑、提交审核、取消排程；发布和撤回不允许批量执行。

## `/admin/content/[id]`

- 字段：标题、导语、摘要、结构化正文、主题、实体、来源、可信状态、重要度、SEO、封面版权、AI 说明。
- 固定操作栏：保存、预览、提交审核；ChiefEditor 额外显示排程、发布、撤回。
- 自动保存不得替代明确保存；离开未保存页面需提示。
- 发布前检查：标题、摘要、作者、主题、来源、SEO、图片版权、风险说明。
- 版本面板显示作者、时间和差异，可从旧版本复制但不能删除历史。

## `/admin/sources` 与 `/admin/sources/[id]`

- 展示来源等级、条款、频率、最近成功、连续失败、24h 新增、噪声率。
- 详情展示配置、健康趋势、最近运行和解析样本。
- 启用来源前必须完成条款状态、负责人和测试抓取。
- 暂停不删除历史；修改 URL、解析器或保留策略属于高风险操作并审计。

## `/admin/runs` 与 `/admin/runs/[id]`

- 状态、任务、计划/实际时间、耗时、统计和错误。
- 详情显示各来源子结果、游标前后值、候选事件和脱敏日志。
- 允许按原始数据重放；重新请求外部来源需额外确认。
- 运行中不可启动相同幂等键；取消只停止未开始的来源。

## `/admin/entities`

- 搜索公司、产品、模型、人物、主题及别名。
- 冲突队列显示同名、低置信度和待合并项。
- 合并前预览受影响内容、候选和 URL；合并后保留旧 slug 重定向。

## `/admin/newsletters`

- 列表显示草稿、排程、发送、送达、退信、投诉和退订。
- 编辑器只能选择已发布内容；支持测试发送、桌面/移动预览和取消排程。
- 最终发送仅 ChiefEditor/Admin；发送后内容不可改，只能创建更正版。
- 收件人排除未确认、退订、退信和投诉地址。

## `/admin/audit`

- Admin 只读查看操作人、动作、对象、时间、request/run ID 和变更摘要。
- 支持时间、角色、动作和对象筛选；敏感值继续脱敏；不可通过 UI 删除。

## 后台完成标准

- 每个页面具备 loading、empty、error、conflict 和 permission-denied 状态。
- 所有高风险操作二次确认并说明影响范围。
- 所有列表可键盘操作，表单错误定位到字段。
- 普通 Editor 无法通过 UI 或直接接口完成发布、发送和来源管理。
