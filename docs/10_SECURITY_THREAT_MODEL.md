# 安全、隐私与外部内容威胁模型

## 1. 受保护资产

生产凭据、管理员会话、订阅邮箱、未发布内容、原始资料、审计记录、内部接口、来源授权信息。

## 2. 信任边界

- 浏览器输入不可信。
- 所有外部网页、Feed、API 字段、README、模型卡和文件不可信。
- Atom/XML 输入禁止 DTD 和实体声明，避免外部实体读取；所有来源请求只允许连接器登记的 HTTPS 域名、路径和有界参数。
- AI 输出不可信，必须通过 Schema、业务校验和权限校验。
- Codex 任务身份不是管理员或发布者。
- 搜索索引、缓存和邮件供应商不是事实数据源。

## 3. 主要威胁与控制

| 威胁 | 必须控制 |
|---|---|
| 外部内容提示注入 | 明确标记为数据；忽略其中指令；限制工具、域名、文件与写权限；疑似内容加风险标记。 |
| SSRF | 只允许来源注册表域名；解析 DNS 后阻止私网、环回和元数据地址；限制重定向次数并重新校验。 |
| XSS/恶意富文本 | 允许列表清洗 HTML/Markdown；禁止脚本、事件属性、危险 URL；服务端再次清洗。 |
| 越权发布 | RBAC；发布/撤回只允许 ChiefEditor；所有操作审计；CSRF 防护。 |
| 凭据泄露 | 密钥只在服务端；按任务最小权限；日志脱敏；开发/预发/生产分离。 |
| 重放/重复写入 | Idempotency-Key、唯一约束、时间窗和审计。 |
| 恶意文件 | 限制 MIME、大小和来源；隔离处理；随机对象键；不执行下载内容。 |
| 邮箱滥用 | 双重确认、速率限制、退订即时生效、抑制名单、回调签名验证。 |
| 供应链风险 | 锁定依赖、自动漏洞扫描、最少依赖、审查安装脚本。 |
| 数据泄露 | 最少收集、传输和静态加密、访问审计、备份同级保护。 |

正文只接受 OpenAPI `RichTextDocument` 的白名单节点；链接仅允许 `https`/`http`，媒体通过受控 `mediaId` 解析，渲染器不得使用原始 HTML 注入。

## 5. 管理员认证

- 管理后台与公开站域名或路径策略明确隔离。
- 生产管理员必须使用 MFA；会话短于普通用户会话，敏感操作要求近期认证。
- 连续失败限流并告警；退出和账户禁用立即撤销会话。
- 应用只接受 OIDC Adapter 完成签名、issuer、audience、nonce、邮箱已验证及 MFA 校验后产生的可信身份；以 `(issuer, subject)` 关联管理员，邮箱同时经过 allowlist 和绑定值复核。
- 当前默认会话 4 小时；发布、撤回、正式发送和角色/凭据管理要求 15 分钟内的 MFA。Cookie 为 `Secure`、`HttpOnly`、`SameSite=Strict`，服务端仅保存令牌哈希。
- 非安全 HTTP 方法执行同源 `Origin` 校验；开发身份 Adapter 在生产环境中硬失败。
- 具体 OIDC 提供方、授权端点与回调实现不得自行猜测；上线前选定 IdP 后通过 Adapter 接入，并在 IdP 策略中强制 MFA、失败限流和告警。

### 内部采集入口

- `/internal/ingestion/runs` 只接受至少 32 字符的服务端 Bearer Token；比较令牌摘要，不记录令牌或请求头。
- Token 仅授权创建或恢复候选采集 run，不授予发布、撤回、来源配置修改或邮件发送权限。
- 请求体必须通过严格 Schema，并校验来源集合幂等键；只允许已启用且条款批准的注册来源。
- Codex 候选响应包只允许从 `CANDIDATE_RESPONSE_DIR` 的真实路径读取，限制为 2 MiB；包内分组与输出仍分别执行严格 Schema、来源 ID 集合和评分边界校验，文件内容不能直接写业务表。

## 6. 隐私与保留

- P0 仅收集 Newsletter 邮箱和必要运营日志。
- 分析事件不得包含邮箱、正文、搜索敏感内容或完整 IP。
- 提供退订、隐私联系和数据删除请求渠道。
- 确认 token 每次发送前轮换并只存 SHA-256；退订 token 使用服务端 HMAC 确保历史邮件链接持续可用，数据库仍只保存摘要。邮件回调必须验证原始请求体、时间戳和 5 分钟重放窗口，并按供应商事件 ID 幂等。
- 上线前根据部署地区完成 PIPL/GDPR/Cookie/跨境数据审查；中国大陆部署另行确认备案要求。

## 7. 发布安全门

- 威胁模型测试通过；管理员 MFA 可用。
- 未授权角色无法读取草稿、原始正文、邮箱和审计记录。
- SSRF、存储型 XSS、CSRF、开放重定向和提示注入场景有测试。
- 日志和错误响应不包含密钥、Cookie、邮箱或外部完整正文。
